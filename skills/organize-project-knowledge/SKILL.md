# Organize Project Knowledge

Keep project context easy to recover as it grows. Prefer the smallest structure
that makes the current project understandable.

## Find the source of truth

1. Resolve the Nova root from this skill's location under
   `skills/organize-project-knowledge/SKILL.md`.
2. Locate the project's source repository and any related area under
   `second_brain/projects/`.
3. Read the nearest project instructions and existing notes before changing
   their organization.
4. Identify what is current truth, historical context, source evidence,
   unresolved work, and temporary working material.

Keep detailed technical truth in the project's own repository when possible.
Use Nova for durable context that should follow the owner across agents. For an
external project, a compact pointer with its name, location, purpose, and useful
context may be enough.

## Shape the project area

Do not create a fixed scaffold or empty placeholder files. Start with one clear
note or folder, then separate information only when doing so improves
navigation.

As a project grows, useful boundaries may include:

- a read-first current-state note;
- history or a decision timeline;
- source and investigation notes;
- agent working context or handoffs;
- preserved artifacts that cannot be linked reliably.

Choose names that explain the contents without requiring knowledge of the
conversation that created them. Keep current truth concise and link to detailed
evidence instead of copying it.

## Organize existing knowledge

1. Preserve meaningful source material and history.
2. Consolidate duplicated current facts into one clear home.
3. Mark assumptions, proposals, and historical conclusions so they are not
   mistaken for confirmed truth.
4. Replace unnecessary duplication with links or short pointers.
5. Move durable conclusions out of temporary notes when their long-term home
   is clear.
6. Leave uncertain placement unchanged or make the smallest reversible move.

Do not rename, move, merge, or delete substantial existing knowledge without
confirming that references and owner intent will be preserved.

## Verify

Confirm that a new agent can quickly answer:

- What is this project and where does its work live?
- What is true now?
- What changed or was decided?
- Where is the supporting evidence?
- What remains unresolved?

Finish by reporting what became easier to find, what was intentionally left in
place, and any organization decision that still needs the owner.
