# Agent second brain

Shared working context for agents when the work concerns Nova as a whole or
spans multiple projects.

When one project clearly owns the context, keep it in that project's
`agents-second-brain/` instead. The project may live under `projects/` or in an
external source repository. Do not maintain the same note in both places.

`dailies/` is an optional daily workspace for planning, recent context, tasks,
and decisions in progress. Add another note or folder when it makes the context
clearer. Move durable outcomes to their clearest long-term home.
