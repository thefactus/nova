# Second brain

This is Nova's home for knowledge that is useful but too detailed for compact
memory.

Use it for project state, decisions, investigations, communications, and
history. Link to source material instead of duplicating it.

## Starting structure

```text
second_brain/
  agents-second-brain/   shared work between agents
  projects/              project knowledge
```

This is a useful beginning, not a fixed taxonomy. The owner can add, rename, or
remove areas as their Nova evolves.

A project may keep its own `agents-second-brain/` for local working context.
The root `agents-second-brain/` is available for work that spans projects or
belongs to Nova as a whole. Projects in external repositories may also keep an
`agents-second-brain/` beside their source code.

Keep current truth separate from historical notes when a subject grows beyond
one file.

Do not store credentials, authentication state, caches, transcripts, or other
private runtime data.
