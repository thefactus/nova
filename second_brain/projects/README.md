# Projects

Keep one clearly named folder for each project.

Inside it, organize knowledge around what helps the project stay understandable:
current context, decisions, history, sources, and working notes. As the project
grows, separate current truth from historical material and give important
subjects their own files.

A project may also keep an `agents-second-brain/` for agent working context and
handoffs. There is no required internal structure; let the project shape its
own organization.
